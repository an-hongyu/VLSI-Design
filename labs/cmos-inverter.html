4. What should students notice?

A balanced beta ratio places the switching point near VDD/2. The output inverts the input.

Model equations

β = μCox(W / L)
βp/βn = (μpCoxWp)/(μnCoxWn)
In(Vin,Vout) = Ip(Vin,Vout)

Equal channel lengths are assumed for the ratio. DC current balance determines the ideal open-circuit output voltage.

Model scope: Open-circuit means no externally connected load (not zero intrinsic capacitance). The displayed input pattern is fixed and the output is mapped quasi-statically through a long-channel square-law DC model (λ = 0.06 V⁻¹). No switching frequency, load capacitance, real-time propagation delay, parasitic capacitance, or energy is calculated. An actual open-circuit output still has intrinsic parasitic capacitance and finite delay. This is an educational model, not SPICE or silicon measurements.
