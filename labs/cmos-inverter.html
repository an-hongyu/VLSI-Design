GRAPH 2 · DYNAMIC RESPONSE

Propagation Delay and Transition Times

Compare input and output transitions, using the same selected inverter design.

(a) Propagation delay — 50% input to 50% output

Measure: Input passes 50% VDD (blue cursor A), then output passes 50% VDD (orange cursor B). The time between A and B is tpHL or tpLH, named for the output transition.

(b) Output rise/fall times — 10% to 90%

Measure: tr is the output 10% → 90% interval; tf is 90% → 10%. Neither is the same as propagation delay.

Balanced: tpHL = 2.90 ps · tpLH = 2.90 ps · tr = 6.61 ps · tf = 6.61 ps
